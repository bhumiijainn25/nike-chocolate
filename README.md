# 🍫 Nike Chocolate – Premium Chocolate Experience

A modern, responsive **Next.js 16** website showcasing a premium chocolate brand inspired by elegance, luxury, and rich flavors. The project features a beautiful landing page with smooth animations, responsive layouts, optimized images, and a clean user experience.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/bhumiijainn25/nike-chocolate.git
```

Navigate to the project directory:

```bash
cd nike-chocolate
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
